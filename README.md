# kitty-lang-front

냥냥 언어 앱의 프론트엔드(1단계). 서버 없이 폰 안에서만 동작하는 일본어 읽기 앱이에요.

## 들어 있는 것

- 홈: 삼색 고양이, 오늘의 30분 목표, 오늘 할 일 4가지, 내 기록
- 글 고르기: 난이도(입문/초급)와 주제로 거르기, 읽기 진행 표시
- 읽기: 후리가나 켜고 끄기, 글씨 크기, 단어를 눌러 뜻 보기와 저장, 글 저장
- 퀴즈: 글 하나당 4문제(읽기, 뜻, 빈칸, 내용), 틀린 단어를 단어장에 담기
- 단어장·복습: 저장한 단어 목록, 카드 뒤집기 복습(1일 → 3일 → 7일 간격), 간식 보상
- 설정: 후리가나 기본값, 글씨 크기, 화면 모드, 기록 지우기

저장은 전부 `localStorage`(키 `kitty-lang-v1`)에 하고, Supabase 연결과 친구와의 기록 공유는 다음 단계예요.
영어 글과 AI 문장 설명도 2단계 이후예요.

## 기술 선택

- **Vite + React + TypeScript**: 화면이 6개이고 저장 단어, 복습 일정 같은 상태가 여러 화면에 걸쳐서, 상태 기반 UI가 편해요. 나중에 Supabase를 붙이기도 쉬워요.
- **Capacitor 안드로이드**: 웹 코드를 그대로 APK로 감싸요. 카메라나 알림 같은 기기 기능이 필요해지면 플러그인으로 추가해요.
- **라우터 없음**: 화면이 적어서 상태 하나로 화면을 바꾸고, 안드로이드 뒤로가기 버튼은 `history`로 맞췄어요.
- **글 본문 표기**: `{漢字|よみ|뜻|뒤에 붙는 가나}` 형식이에요. 후리가나와 단어 뜻이 한 곳에 있어서 글을 추가하기 쉬워요. 글은 `src/data/articles.ts`에 있어요.

## 실행

```sh
npm install
npm run dev            # 브라우저에서 확인
npm run android:sync   # 빌드 후 안드로이드 프로젝트로 복사
npm run android:open   # Android Studio에서 열어 APK 만들기
```

Android Studio와 JDK 17 이상이 필요해요.
