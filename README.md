# kitty-lang-front

냥냥 언어 앱의 프론트엔드(1단계). 서버 없이 폰 안에서만 동작하는 일본어 읽기 앱이에요.

## 들어 있는 것

- 홈: 삼색 고양이, 오늘의 30분 목표, 오늘 할 일 4가지, 내 기록
- 글 고르기: 난이도(입문/초급)와 주제로 거르기, 읽기 진행 표시
- 읽기: 후리가나 켜고 끄기, 글씨 크기, 단어를 눌러 뜻 보기와 저장, 글 저장
- 퀴즈: 글 하나당 4문제(읽기, 뜻, 빈칸, 내용), 틀린 단어를 단어장에 담기
- 단어장·복습: 저장한 단어 목록, 카드 뒤집기 복습(1일 → 3일 → 7일 간격), 간식 보상
- 설정: 후리가나 기본값, 글씨 크기, 화면 모드, 기록 지우기

저장은 먼저 `localStorage`(키 `kitty-lang-v1`)에 하고, 로그인하면 숫자만 Supabase와 맞춰요. 인터넷이 없어도 그대로 쓰고, 연결되면 알아서 올려요.
영어 글과 AI 문장 설명도 2단계 이후예요.

## 친구와 같이 하기 (Supabase)

- 홈: 독해 완료 기준으로 하루를 판정(30분을 못 채워도 돼요)
- 기록 탭: 달력. 내가 글을 읽은 날은 큰 발바닥, 친구도 읽은 날은 겹친 발바닥 두 개
- 같이 탭: 로그인, 친구 오늘 기록, 응원 보내기/받기(오프라인에서 누르면 연결될 때 전송), 공동 목표
- 서버에 올라가는 것은 하루별 숫자(학습 시간, 읽은 글 수, 복습 단어 수, 퀴즈 맞힌 수/푼 수)뿐이에요.

### 설정
1. [kitty-lang-back](https://github.com/randalll09/kitty-lang-back)의 `supabase/migrations/*.sql`을 파일 순서대로 SQL Editor에서 실행해요. (파일 이름이 아니라 내용을 붙여 넣어요.)
2. Supabase 대시보드 → Authentication → Providers → Email 에서 **Confirm email** 을 꺼요. 메일 확인이 켜져 있으면 가입이 막혀요.
3. `.env.example` 을 `.env` 로 복사하고 Project URL 과 anon key 만 넣어요. service_role key 와 비밀번호는 넣지 않아요.
4. 두 사람이 모두 가입하면 자동으로 이어져요. 그 뒤에는 Authentication 설정에서 신규 가입을 꺼 두는 걸 권해요.

로그인은 이메일+비밀번호예요. 두 사람만 쓰는 앱이라 가장 단순하고, 폰을 바꿔도 같은 계정으로 돌아올 수 있어요. 익명 로그인은 앱을 지우면 기록이 끊기고, 메일 링크는 안드로이드 딥링크 설정이 더 필요해요.

## 기술 선택

- **Vite + React + TypeScript**: 화면이 6개이고 저장 단어, 복습 일정 같은 상태가 여러 화면에 걸쳐서, 상태 기반 UI가 편해요. 나중에 Supabase를 붙이기도 쉬워요.
- **Capacitor 안드로이드**: 웹 코드를 그대로 APK로 감싸요. 카메라나 알림 같은 기기 기능이 필요해지면 플러그인으로 추가해요.
- **라우터 없음**: 화면이 적어서 상태 하나로 화면을 바꾸고, 안드로이드 뒤로가기 버튼은 `history`로 맞췄어요.
- **글 본문 표기**: `{漢字|よみ|뜻|뒤에 붙는 가나}` 형식이에요. 후리가나와 단어 뜻이 한 곳에 있어서 글을 추가하기 쉬워요. 글은 `src/data/articles.ts`에 있어요.

## 실행

```sh
npm install
npm run dev            # 브라우저에서 확인
npm run android:sync   # 빌드 후 안드로이드 프로젝트로 복사
npm run android:open   # Android Studio에서 열어 APK 만들기
```

Android Studio와 JDK 17 이상이 필요해요.
